# Contributing

Improve one lesson, exercise, project, or guide at a time. Preserve the local-first approach, practical Northern Nigerian and global community contexts, and accessible language. Do not add paid-service requirements or undocumented cloud dependencies.

Before opening a pull request, run:

```bash
python3 scripts/validate_curriculum.py
python3 scripts/validate_links.py
```

Describe the learner outcome, test evidence, offline effect, and any version-sensitive source you verified. Keep student submissions in their own repositories rather than this repository.
